Reports use an approximate location. Read the website privacy policy.

How it works

  • Web app

    Next.js, React, and TypeScript power the browser interface. No app installation is needed.

  • Map and data

    Leaflet and OpenStreetMap provide the map. PostgreSQL stores reports for viewing by place and time.

  • Location privacy

    Report locations are randomly shifted before storage. Reporting does not require an account, name, or email.

  • Context and report quality

    Open-Meteo adds wind and weather data. Server-side location checks and report limits help reduce false and repeated reports.
